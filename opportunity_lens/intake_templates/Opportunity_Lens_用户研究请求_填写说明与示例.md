# Opportunity Lens 研究请求模板：填写说明与示例

本文件是说明文件，不是正式填写框。正式提交给 Agent 时，请使用 `Opportunity_Lens_用户研究请求_正式填写模板.md`。

---

# 一、字段说明

## 必填 1：研究问题

写清楚这次到底要回答什么。可以是一句话，也可以是一小段。

示例：

```text
未来 12 个月，全球存储上游哪些材料可能出现供需失衡？A 股哪些公司可能真实承接？
```

```text
在长江存储/长鑫存储扩产背景下，中国半导体材料公司中哪些只是主题映射，哪些真正具备公司承接能力？
```

---

## 必填 2：可用资料状态

只选 A / B / C 中的一个。

```text
A. 无资料
```

适合只有开放问题，没有研报、数据库、候选文件的情况。系统会进入 C-Open，先做全球多语言 文献综述、候选发现、数据充足度判断和补充资料建议。

```text
B. 有 papers / 研报文件夹
```

适合已有 papers 或研报文件夹。系统会进入 C-Paper，把 papers 当 seed，但仍然独立做全网多语言搜索、核验和补充，不会直接继承报告结论。

```text
C. 有可以参考的行研库行业
```

适合现有 `industry_demo` 行研库中已有相关行业，例如存储、半导体材料、先进封装、半导体设备等。系统可以只读参考 A/B 轨资料，但不能照抄，也不能写入或污染 A/B 轨数据库。

填写示例：

```text
选择：A
资料路径 / 行研库行业名称：
补充说明：无
```

```text
选择：B
资料路径 / 行研库行业名称：D:\quant\industry_demo\papers\半导体材料
补充说明：其中部分研报较旧，需联网补充最新价格、产能和事件。
```

```text
选择：C
资料路径 / 行研库行业名称：存储、半导体材料、先进封装
补充说明：仅作只读参考，仍需做全球多语言 文献综述。
```

---

## 必填 3：证据策略

只选 A / B / C 中的一个。

```text
A. freshness_first / 时效优先
```

适合找前瞻机会、产业链异动和早期信号。允许更宽的 source 范围，包括产业媒体、纪要、论坛/KOL 等弱信号；但所有来源必须入库、聚类、标注、展示正反方和待核验项。灰源不能单独变成高置信核心事实。

```text
B. balanced / 平衡
```

默认常规投研模式。既做全球多语言搜索，也保持正常 source review、calculation review、coverage/confidence 和评分约束。

```text
C. accuracy_first / 准确优先
```

适合内部正式汇报、严谨预期判断和复核任务。更依赖公告、交易所、公司官网、政府/海关、行业协会、权威数据库和可信媒体。灰源只做线索或市场热度，不进核心评分。

填写示例：

```text
选择：A
```

```text
选择：B
```

```text
选择：C
```

# 二、选填字段说明

## 选填 1：时间窗口

默认值：

```text
核心窗口：未来 12 个月
长期背景：未来 3 年
```

接受默认时，在正式模板里写：

```text
是否使用默认：是
```

自定义示例：

```text
是否使用默认：否
核心窗口：未来 6 个月
长期背景：未来 2 年
```

---

## 选填 2：研究范围

默认值：

```text
全球多语言搜索；不预设候选池；系统可以自行扩展候选。
```

接受默认时，在正式模板里写：

```text
是否使用默认：是
```

自定义示例：

```text
是否使用默认：否
地理范围：全球，但重点关注中国、日本、韩国和美国
行业 / 环节：存储上游材料、电子特气、光刻胶、先进封装材料
公司 / 材料候选：WF6、ArF/ArFi 光刻胶、HBM EMC、中船特气、彤程新材、安集科技
必须包含：长江存储、长鑫存储、三星、SK 海力士、美光相关线索
必须排除：纯消费电子终端公司
```

---

## 选填 3：特殊约束

默认值：

```text
无
```

接受默认时，在正式模板里写：

```text
是否使用默认：是
```

自定义示例：

```text
是否使用默认：否
特殊约束：
- 不使用 KOL/论坛作为核心证据
- 必须覆盖日文/韩文来源
- 必须单独列出反方证据
- 不输出公司排序，只做环节分析
- 只看上市公司
```
