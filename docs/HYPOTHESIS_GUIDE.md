# 研究员投资假说 · 填写指引(给研究员看)

系统把"行业标签"升级为"以人为标签":每位研究员用自己的名字,沉淀**可跟踪、可证伪、可交易**的投资假说。
入口:顶栏 **?? 研究员观点** → 右上角 **+ 新建假说**。

> 系统只是工具,不替你思考。所有内容由你本人填写;AI 只帮你**扫关键词、标红提示**,**绝不替你判断信号是否触发,绝不给买卖建议**。

---

## 一条合格假说的最小要件(正式提交必填)

1. **作者 + 标题 + 方向**(看多 / 看空 / 中性 / 反共识)
2. **假说陈述** —— 你的核心判断、推理链条、关键假设。*不需要目标价(那是 PM 的事)。*
3. **≥1 个证伪条件**(falsification signal)—— "出现什么,我就认错"
4. **正向交易**(primary)—— 基于假说做什么:方向 + 标的类型(可到板块/公司,也可纯文字)
5. **证伪后反向交易**(falsification_reverse)—— **梁总硬要求**:假说被证伪后,你转做什么

> 还没想清楚?点 **保存草稿**(只需作者 + 标题),稍后补全再正式提交。

---

## 各字段说明

- **信心 L1–L5**:你对该假说的主观信心,后续可在更新里调整(下调会留痕)。
- **持有期 horizon**:3 / 6 / 12 / 24 个月。
- **板块 / 公司标签**:挂到 10 大板块(大模型/AI应用/芯片/半导体/存储/光模块/交换机/云服务器厂商/液冷散热/电力)和公司池;同一行业页能横向看不同研究员的不同判断。
- **引用材料**:研报 / 新闻 / 意见领袖发言 / 事件,搜索后多选。引用 id 必须真实存在,系统会校验;陈述里写 `^src:N`(N=研报 id)可点击溯源原文。
- **监控信号**:
  - *证伪条件* = 触发就证伪;*确认信号* = 触发就强化;*中性观察* = 只看不结论。
  - *AI 检测关键词*(逗号分隔)= 系统扫近 7 天新闻/发言,命中就在你的假说页"系统提示"区标红、在新闻流挂 ??。**是否真触发,你来判断。**
- **交易方案**:仓位 / 入场触发 / 出场触发都可选填。

---

## 假说的生命周期(全程留痕)

- 在假说详情页:更新信号状态(?? 更新)、改交易方案、编辑假说本身。
- **每次改动都追加一条更新日志**(版本化,旧值留快照,绝不抹掉历史)。
- 假说不删除,只能置为 **已撤回(withdrawn)**。
- 状态:跟踪中 → 部分证伪 / 已证伪 / 已确认 / 已撤回。

---

## 反 slop 约定(为什么这么设计)

- 系统不预填任何假说;空着就是空着,等你填。
- AI 只做"信息聚合 + 关键词标红",不下结论、不荐股。
- 引用必须能溯源到真实 source/news/voice/event。
- 每条 numeric 判断尽量带单位与出处。
