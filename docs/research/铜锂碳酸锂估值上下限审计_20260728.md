# 铜、锂与碳酸锂估值上下限审计

审计日期：2026-07-28  
市场比较时点：铜 A 股与锂公司为 2026-07-24；五矿资源为 2026-07-26 抓取的港股市值折算。

## 审计结论

用户记得的“正常化市盈率相对当前市值约 -3%～+23%”来自旧版洛阳钼业结果，并不是紫金矿业；旧版紫金本来显示约 +26%～+57%。但这不代表旧版计算正确。复核发现四类实质问题：

1. 铜计算器曾把冻结目标市值复制进前端，再用另一套利润反推倍数，目标值、利润和倍数不是同一合同。
2. PB—ROE 的价值端使用过平均权益，而模型说明写的是期末权益；部分倍数是从目标价值反推，而不是由可持续 ROE 公式产生。
3. 铜 DCF 曾被简化成“自由现金流×价值倍数”，锂 DCF 则对单点结果机械加减百分比，均不能解释上下限来自哪里。
4. 锂计算器只接收 PE 中值，导致上下限在前端合并成同一点；同时把核心、参考和诊断方法的最小值与最大值合并成一个“总区间”，会把不可比的方法伪装成一致结论。

本轮已改为：每个估值结果都从同一组经营输入直接计算；低值与高值分别公开利润、净资产、ROE、倍数、股权成本和长期增长；核心方法与诊断方法分开。西藏城投因预测利润、ROE和项目现金流均不满足门槛，撤销原来没有完整底稿的数值区间，不再造一个最低 PB 或条件 NAV。

## 统一计算合同

### 正常化市盈率

**目标股权价值＝正常化年度归母净利润×目标市盈率。**

上下限不是从目标市值倒推，而是先选定正常化年度和利润，再以近期市场前瞻倍数、最近两个季度可核验机构报告及公司资源质量、项目成熟度、资本强度和国家风险确定倍数范围。周期公司的高利润和高倍数不能同时永久化。

### PB—ROE

**合理 PB＝（可持续 ROE－长期增长率）÷（股权成本－长期增长率）。**

**目标股权价值＝正常化年度期末归母净资产×合理 PB。**

铜公司按各自风险设定可持续 ROE、股权成本和长期增长。锂公司低值统一使用较高股权成本 12.5% 和较低长期增长 2.0%，高值使用 10.5% 和 3.0%；可持续 ROE 上限不超过 22%，下限再根据资源覆盖、项目成熟度和业务质量折减。PB—ROE 只有在净资产能代表已投产经营资本时才有意义。

### 股权自由现金流折现

**股权价值＝Σ[FCFEₜ÷(1＋Ke)ᵗ]＋FCFE末期×(1＋g)÷(Ke－g)÷(1＋Ke)ⁿ。**

低值使用较高股权成本和较低长期增长，高值相反。区间来自参数敏感性，不再对单点结果机械加减 15%。由于公开资料尚不能为所有矿山逐年拆出维持资本、营运资金和矿山寿命，DCF/FCFE主要承担现金流交叉验证；终值占比较高的结果不升为唯一目标价。

西藏城投只确认了国能矿业 41%权益和规划产能；缺少同口径储量采序、回收率、建设及维持资本、单位成本、税制和投产时间，且公司还包含地产等非锂资产。现有资料既不足以形成项目 NAV，也不足以把锂项目数值与公司总市值直接比较，因此撤销没有完整现金流底稿的旧数值，不再设置 0.35 倍 PB 下限。

## 对铜、锂和碳酸锂研究结论的影响

- 铜行业：紫金矿业从“多方法均显示显著低估”修正为“PE下沿略有余量、PB已在区间内、DCF接近下沿”；洛阳钼业修正为“市场位于PE上部并高于PB/DCF”；五矿资源维持“市场要求较强兑现”，但依据改为三种可复算结果。
- 锂和碳酸锂：行业页的核心研究区间只采用正常化PE，不再把PB或FCFE的低值混入核心区间。PB和FCFE仍完整展示，但明确是资产回报或现金流诊断。
- 雅化集团、天华新能和中矿资源在PE核心方法下显示正向空间，但PB/FCFE明显更保守，说明上行依赖项目兑现和现金转换，不能把PE上沿直接当目标价。
- 大中矿业、永杉锂业在核心PE下也高于研究上限，属于需要业绩显著超出当前独立模型才能解释的市场定价。
- 西藏城投改为不评级；“没有足够数据”不再被最低PB或无底稿NAV伪装成可计算结果。

## 已同步位置

修正已进入铜、锂、碳酸锂的主文档、估值对比、公司透视、公司详情财务模型、两个网页计算器及 `financial.db` 的新版本模型。计算器中每个方法均展示公式、实际代入、参数上下限、依据、角色和限制；浏览器保留研究员手动调整能力，但参数变化会从经营输入向估值结果重新计算，不能只改结果数字。
