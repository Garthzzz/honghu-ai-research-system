# 公司财务建模与 PB—ROE 估值：研究员使用手册

版本：`research.modeling_skills.v1` 研究员版  
适用范围：A/B 行研、Opportunity Lens、公司详情页及行业计算器中的公司模型。

## 1. 这套系统解决什么问题

这套系统不是让 Agent 随手给出一个目标价，而是把“公司为什么能赚钱、未来利润怎样形成、市场已经计入多少预期”拆成一条可以检查的计算链。

研究员最终应看到四类结果：

1. **独立盈利预测**：FY1—FY3 的收入、利润、EPS、现金流和资产回报来自哪些业务变量。
2. **多方法估值**：哪些方法适用、各自得到什么区间、为什么存在差异。
3. **外部对账**：独立模型与公司指引、Wind 一致预期、近期卖方预测和当前股价隐含预期有何不同。
4. **行动结论**：当前价格是否有安全边际，什么事实支持加仓、等待或减仓。

它不保证每家公司都有完整 DCF、PB—ROE 或五年精确预测。数据不足时，系统应主动降级为财务桥、历史/同行诊断、反向估值、阈值或情景分析，而不是补造数据。

## 2. 数据放在哪里，为什么要分层

随时更新的 Wind、Tushare 和 yfinance 财务与市场数据进入 `financial.db`，不会重复写成普通行研数据点。研究报告保存的是截止研究日冻结的模型、判断和对账结果，公司页读取最新财务库数据并保留冻结模型版本。

财务数据分为六类，研究员阅读时不能混用：

| 数据身份 | 含义 | 常见例子 | 用法 |
|---|---|---|---|
| 实际值 | 已披露或已发生 | 年报收入、净利润、经营现金流 | 历史基线和会计核对 |
| 市场值 | 市场交易形成 | 股价、市值、PE、PB | 当前定价和历史估值位置 |
| 一致预期 | 数据商汇总的外部预测 | Wind FY1—FY3 净利润 | 独立模型冻结后的对账 |
| 公司指引 | 公司正式给出的经营范围 | 收入增速、资本开支计划 | 约束模型，不直接替代模型 |
| 内部预测 | 本系统独立建模结果 | FY1—FY3 收入、净利润、ROE | 估值的主要输入 |
| 市场隐含值 | 从当前价格反推 | 当前市值要求的利润或 ROE | 判断市场已经押注什么 |

A 股结构化数据原则上以 Wind 为主，Wind 客观缺失时才由 Tushare 逐字段补充；海外股票主要使用 yfinance。公司公告、交易所和监管披露仍是会计事实的最终权威。两家供应商同口径冲突时保留双方记录，不取平均。

## 3. Agent 如何建立一家公司模型

### 第一步：判断公司是什么“经济机器”

Agent 先判断公司的商业模式、生命周期、周期性、资产属性和利润驱动。例如：

- 资源公司：产量 × 商品价格 − 单位成本；
- 制造业：销量 × 单价，并受产能、利用率、良率和产品结构约束；
- 软件订阅：客户数 × 单客收入，并受续费率、交付成本和销售费用约束；
- 银行：生息资产 × 净息差，再考虑信用成本和资本约束。

公司分类决定后续应使用什么利润模型和估值模型。行业名称相同，不代表经济机制相同。

### 第二步：建立至少三年历史基线

历史表原则上整合收入、毛利率、净利润、经营现金流、资本开支、自由现金流、归母净资产、总资产、ROE 和 ROA。研究员主要检查：

- 利润增长是否真的转成现金；
- 毛利率变化来自价格、产品结构还是成本；
- 资本开支和营运资金是否吞噬现金；
- ROE 来自经营效率，还是杠杆、周期价格或一次性收益；
- 归母利润、少数股东、股本和币种是否使用同一口径。

### 第三步：按数据质量选择预测深度

模型由深到浅分为四级：

| 模型层级 | 适用条件 | 典型做法 |
|---|---|---|
| 完整业务驱动 | 数量、价格、产能和成本较完整 | 产品或项目级量价模型 |
| 市场空间与份额 | 缺少部分量价，但行业空间、份额和产能够用 | 市场规模 × 公司份额，并用产能约束 |
| 财务桥接 | 业务数据有限，但历史财务、订单和指引较完整 | 当前收入 + 行业/新品/产能贡献 − 价格与份额压力 |
| 反向/阈值分析 | 关键经营变量客观不可得 | 反推当前价格要求的利润、份额或利润率 |

最小利润桥为：

```text
收入 → 毛利润 → 经营费用 → 息税前利润 → 利息与税费
     → 少数股东损益 → 归母净利润 → EPS
```

现金流可得时继续计算：

```text
自由现金流 = 经营现金流 − 资本开支
```

缺失现金流不能当作零。竞争进入、政策、技术替代等外部事件，必须先落到认证、产能、销量、价格、份额、成本、费用、资本开支和营运资金，再传导到利润和现金流，不能直接给利润乘一个主观折扣。

### 第四步：独立预测先冻结，再看市场答案

Agent 使用研究截止日前可得事实建立 FY1—FY3 独立模型，并冻结输入、输出和文件哈希。冻结后才读取公司指引、一致预期和近期研报预测。

对账不是把独立结果向一致预期靠拢，而是逐项解释差异：

- 收入差异来自销量、价格、市场份额还是并表范围；
- 利润差异来自毛利率、费用率、税率或少数股东；
- 现金流差异来自资本开支或营运资金；
- 估值差异来自预测年份、倍数、股权价值和企业价值口径。

公司财务预测的卖方中位数只使用研究截止日前最近两个季度发布的同公司报告，并写明机构、日期和预测口径。更早报告可用于解释历史变化，但不能混入当前预测中位数。只有发现新事实、单位/期间错误或模型结构错误时，才能修改独立模型，并保留变更记录。

## 4. 估值方法如何选择

每个方法必须标明“核心、参考、诊断或不适用”，不能为了填满页面强行计算。

| 方法 | 何时有用 | 主要输入 | 常见失真 |
|---|---|---|---|
| Forward PE | 正常盈利且利润可预测 | FY1/FY2 净利润、目标 PE | 周期顶部、一次性利润或亏损公司 |
| EV/EBITDA | 折旧和资本结构重要 | EBITDA、净债务、目标倍数 | 忽略持续资本开支 |
| PS | 尚未正常盈利但收入质量可判断 | 收入、长期利润率、目标 PS | 把低质量收入当高质量增长 |
| DCF/FCFF | EBIT、税率、折旧、CAPEX、营运资金可预测 | 自由现金流、WACC、终值 | 数据不全时容易制造伪精确 |
| PB—ROE | 账面净资产和资产回报有经济意义 | 净资产、可持续 ROE、股权成本 | 把周期高 ROE 或杠杆高 ROE 永续化 |
| SOTP | 分部边界和分部利润/现金流清楚 | 各分部模型、净债务 | 分部重叠或成本分摊不清 |
| NAV/rNPV/DDM | 资源资产、概率项目或资本约束企业 | 资产/概率/股利专用数据 | 将不适用行业机械套入 |
| 反向估值 | 所有正式公司估值至少做一种 | 当前市值、倍数或现金流假设 | 只能解释市场要求，不代表会实现 |

多模型不做机械平均。系统先按共同经营假设分成利润倍数、企业价值、资产回报和诊断模型簇，再解释结果为什么集中或冲突。

## 5. PB—ROE 到底是什么

### 5.1 直觉

PB 表示市场愿意为一元归母净资产支付多少价格；ROE 表示公司用归母净资产创造利润的能力。只有当高 ROE 能持续、覆盖股权资本成本并转成现金，高 PB 才可能有经济依据。

`PB = PE × ROE` 是会计恒等关系，不是估值理由。不能因为公司当前 ROE 高，就直接指定更高 PB。

预测 ROE 必须来自利润与净资产桥：

```text
期末归母净资产
= 期初归母净资产 + 归母净利润 − 分红 − 回购 + 增发及其他权益变动

预测 ROE
= 归母净利润 ÷ 期初与期末归母净资产平均值
```

### 5.2 四条 PB—ROE 路径

#### 路径一：Wilcox 理论桥

它回答：“一家公司未来若能在若干年内持续赚取高于股权成本的 ROE，当前合理 PB 应是多少？”

```text
当前合理 PB
= 长期均衡 PB × exp[(可持续预期 ROE − 股权资本成本) × 优势衰减年数]
```

例如仅作方法演示：可持续 ROE 为 15%、股权成本为 10%、优势持续 5 年、长期均衡 PB 为 1.0 倍，则合理 PB 约为 `1.0 × exp[(15%−10%)×5] = 1.28 倍`。如果 15% ROE 只是商品价格顶部或由高杠杆形成，这个结果不能作为正式目标 PB。

长期均衡 PB 不必等于 1。PB 接近 1 只有在资产可变现、减值风险低、负债可控时，才可能构成有条件的资产保护线。

#### 路径二：可持续增长与多阶段净资产滚动

稳定状态下：

```text
可持续增长率 = ROE × (1 − 分红率)
```

若 ROE 是当期利润/当期净资产口径：

```text
合理 PB
= ROE × 分红率 × (1 + 可持续增长率)
  ÷ (股权资本成本 − 可持续增长率)
```

若输入已经是下一期利润/期初净资产的 forward ROE，则不再乘 `(1+可持续增长率)`。两种口径不能混用，并且长期增长率必须低于股权资本成本。

公司处于高增长、成熟和终态多个阶段时，系统逐年滚动净利润、分红和期末净资产，再折现各年股利与终值。它比把一个高 ROE 永续化更适合真实公司。

#### 路径三：残余收益

它把公司价值拆成现有净资产和未来超额回报：

```text
残余收益_t = (ROE_t − 股权资本成本) × 期初归母净资产_t

股权价值
= 当前归母净资产 + 预测期残余收益现值 + 终值现值
```

ROE 低于股权成本时，新增资本可能毁损价值；ROE 高于股权成本且能持续时，才产生正的残余收益。

#### 路径四：历史与同行经验映射

它回答“过去或可比公司在相似回报水平下，市场通常给多少 PB”，主要用于诊断而不是直接给目标价。

历史映射默认估计：

```text
ln(PB) = 截距 + 系数 × ROE
```

每个财务报告期只匹配披露后的一个月末或事件时点 PB，不能把一个年度 ROE 复制到数百个交易日伪造样本。历史 PB Band 至少需要 12 个独立月末或季度观察；回报—PB 回归至少需要三个真正独立的财务期，并展示样本、拟合质量和残差。历史实际 ROE 只是当时市场预期 ROE 的代理，相关性不等于因果。

### 5.3 PB—ROA 为什么要一起看

PB—ROA 不是另一套目标价公式，而是识别 ROE 质量：

```text
ROE ≈ ROA × 权益乘数
```

如果两家公司 ROE 都是 15%，一家依靠高 ROA，另一家依靠高负债和高权益乘数，前者的回报质量通常更高。系统会结合 ROA、ROIC、权益乘数、负债性质、资产周转率、利润率和现金流解释 ROE，不把经营性负债自动当作有息债务，也不把高杠杆放大的 ROE 直接奖励为更高 PB。

### 5.4 PB“净资产增长＋倍数重估”如何拆解

```text
当前市值 = 当前归母净资产 × 当前 PB
仅净资产增长后的市值 = 预测归母净资产 × 当前 PB
情景市值 = 预测归母净资产 × 目标 PB
```

第一段差额是净资产增长贡献，第二段差额是 PB 扩张或收缩贡献。这个分解能告诉研究员收益依赖盈利积累还是市场重估，但不能证明目标 PB 合理；目标 PB 仍需历史、同行、周期或残余收益依据。

## 6. 简化模式和详细模式怎么用

公司页输入台默认使用简化模式，适合数据不完整但已有可靠利润预测的公司。

### 简化模式最低输入

- 期初归母净资产；
- 冻结的 FY1—FY3 归母净利润；
- 分红率或留存率；
- 当前 PB 和有依据的目标 PB。

系统滚动净资产、ROE、目标市值和 PB 双击贡献。回购、增发及其他权益变动不可得时可暂按零，但必须显示为限制。

### 详细模式附加输入

- 未来总资产、ROA/ROIC；
- 有息负债、现金和权益乘数；
- 经营现金流、资本开支和营运资金；
- 回购、增发、少数股东和其他权益变动。

这些字段齐备后，系统才能拆解资产效率、杠杆和现金回报。缺少未来资产或现金流时，PB—ROA 只作为质量诊断，不能声称已经完成详细三表模型。

研究员手工调整的情景应独立保存、恢复和比较，不覆盖 Agent 冻结模型。

## 7. 研究员怎样阅读公司页结论

建议按以下顺序：

1. **先看经营模型**：收入和利润由什么驱动，关键假设是否符合产能、订单和行业总量。
2. **再看现金质量**：利润是否转成经营现金流，自由现金流是否被扩产吞噬。
3. **再看资产回报**：ROE 是利润率、周转率还是杠杆推动，能持续多久。
4. **再看估值簇**：PE、企业价值、PB—ROE 和现金流方法是否给出相近结论；冲突来自哪里。
5. **再看市场隐含预期**：当前价格已经要求多高的利润、ROE 或增长年限。
6. **最后看行动条件**：当前买入、等待或回避的理由，以及什么事实会推翻判断。

公司页的“综合估值判断与交易观察”应清楚列出：本系统核心区间、市场/一致预期、有无显著分歧、分歧原因、买卖位置、主要催化和证伪条件。它是研究结论摘要，不替代下方模型账本。

## 8. 什么时候不能使用 PB—ROE

以下情况应降级或关闭：

- 净资产为负或账面资产缺乏经济意义；
- 当前利润主要来自一次性收益；
- 周期顶部 ROE 尚未正常化；
- 资产存在重大减值或无法变现；
- 高 ROE 主要由不可持续杠杆形成；
- 未来净利润、分红或净资产路径没有可靠依据；
- 历史 PB 或财务披露时点不足以形成有效配对；
- 轻资产高成长公司账面净资产无法代表核心无形资产，PB 只能低权重参考。

此时可以使用 PE、EV/EBITDA、PS、反向估值、情景 DCF 或经营阈值，但仍必须遵守各自的数据门槛。

## 9. 给 Agent 下任务时，研究员最好说明什么

最低限度说明：

- 公司、ticker、市场和估值截止日；
- 希望回答的是盈利预测、合理价值、市场预期差还是事件冲击；
- 重点业务、商品价格、产能、订单或客户假设；
- 希望使用的情景和投资期限；
- 已掌握的公司指引、内部判断或需要强制核验的研报。

可以直接这样提问：

> 对公司建立 FY1—FY3 独立盈利和现金流模型，先冻结再与最近两个季度卖方预测及 Wind 一致预期对账；按数据条件计算适用的 PE、EV/EBITDA、PB—ROE 和反向估值。请说明每个方法的角色、输入来源、计算过程、市场隐含预期、核心价值区间以及加仓和证伪条件。若数据不支持详细 PB—ROE 或 DCF，请降级并说明原因，不补造数据。

## 10. 最终验收清单

- 是否统一币种、单位、财年、归母口径、股本和少数股东；
- 是否至少有三年历史基线；
- FY1—FY3 是否在外部一致预期之前独立冻结；
- 每个关键输入是否有来源、期间、单位和事实身份；
- 模型复杂度是否与数据质量匹配；
- 利润是否继续传导到现金流、净资产、ROE/ROA；
- 每个估值方法是否写明适用角色、公式、代入和局限；
- 是否至少有一种反向估值；
- 目标倍数是否有历史、同行、周期或经济依据；
- 是否逐变量对账，而非只比较最终目标价；
- 多模型是否解释共同输入和冲突，而非机械平均；
- 结论是否给出明确买入/等待/回避理由及证伪条件。
