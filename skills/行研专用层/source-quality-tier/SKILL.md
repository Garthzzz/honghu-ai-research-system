# Source Quality V2

判断维度：身份、是否一手、发布时间、原文可见性、利益相关、口径完整、可复算、与更强来源冲突、底层独立性。

来源数量和独立来源数量分开：多篇文章引用同一公告、同一访谈或同一数据库表，只算一个 `independence_key`。

用途分层：

- 官方/监管/公司原始披露：核心事实候选；
- 权威行业组织/数据库：核心或强支持；
- 可信媒体：事件核验或支持，重大结论需交叉验证；
- 卖方/专家纪要：框架、预测和线索，明确利益相关与前瞻性；
- KOL/论坛/传闻：early signal，不进入核心分。

旧材料可作结构和回测，不能单独支撑当前判断。
