# 公司财务建模

## 硬合同

1. 先统一币种、单位、财年、归母/整体、持续经营/一次性项目、股本和少数股东口径。
2. 先用截至估值日可得的事实建立 FY1-FY3 独立预测并冻结输入、输出和 SHA256；冻结前不得读取一致预期作为答案。
3. 冻结后才读取公司指引、一致预期和研报预测，逐变量对账。只有新事实或计算错误可以修改独立结果，且必须留下变更记录。
4. 模型复杂度服从数据：优先业务驱动；缺关键量价时降级为市场空间/份额或财务桥；仍不足时做阈值、反向或区间分析，不造数。
5. 外部事件必须依次落到认证/产能/数量/价格/份额/成本/费用/资本开支/营运资本，再进入收入、利润与现金流；禁止直接给收入或利润乘主观折扣。
6. 所有模型输入区分 `actual`、`guidance`、`consensus`、`internal_estimate`、`implied`，并保存来源、时点、单位、范围和局限。
7. 涉及 PB—ROE 或重资产/周期公司时，利润路径必须继续传导到净资产和资产回报，不能用利润增速代替 ROE。最小净资产桥是：
   `期末归母净资产＝期初归母净资产＋归母净利润－分红－回购＋增发及其他权益变动`；
   `预测ROE＝归母净利润÷期初与期末归母净资产平均值`。
8. 模型分为简化与详细两级。只有期初归母净资产、冻结净利润路径和有依据的留存率时，可做简化权益桥，但必须把缺失的回购、增发和其他权益变动写成限制；只有未来资产、杠杆、现金流和资本开支路径齐备时才声称完成详细模型。

## 最小输出

- 公司经济机制与数据等级；
- 至少三年历史财务基线；
- FY1-FY3 独立预测和冻结哈希；
- 关键公式、代入值、结果与可复算账本；
- 基准/上行/下行情景的经营差异；
- 与指引、一致预期或研报逐变量对账；
- 风险、证伪条件与置信度。

## 预测桥

最小利润桥为：

`收入 → 毛利润 → 经营费用 → 息税前利润 → 利息/税费 → 少数股东损益 → 归母净利润 → EPS`

现金流资料可用时继续：

`经营现金流 − 资本开支 = 自由现金流`

不得把缺失的现金流字段自动补成零。复合公司默认先做合并财务；只有分部收入、利润或资产边界足够时才做分部模型/SOTP。

## 周期与资产回报传导

重资产或周期公司先写清价格、产量/销量、单位成本、产能利用率和资本开支怎样进入利润，再判断总资产与净资产增长是否快于利润。必须直接回答未来三至五年 ROE 是上升、持平还是下降，以及高 ROE 来自经营效率、周期价格还是杠杆。

ROA、ROIC、有息负债、经营性负债、经营现金流和资本开支是质量检查，不是为了填满表格。字段客观不可得时，保留简化权益桥并降级结论；不得把总负债自动解释为有息债务，也不得把经营性占款自动解释为财务风险。
